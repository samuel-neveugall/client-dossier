# Sources

Les sources sont immuables. Rien sous ce dossier n'est jamais modifié ni corrigé, même quand un
transcript est faux — les corrections vont dans les fichiers vivants sous `dossier/`, jamais ici.

- `received/` — documents reçus de la contrepartie ou du client final : plaquettes, briefs,
  contrats, tout ce qui nous est envoyé.
- `transcripts/` — enregistrements d'appels et leurs transcripts ; `transcripts/raw/` contient
  le transcript automatique, non relu, tel que produit.

Les fichiers sont nommés `YYYY-MM-DD_slug` (plus leur extension). L'extraction texte d'un PDF est
placée à côté du PDF, même radical, extension `.txt`.
