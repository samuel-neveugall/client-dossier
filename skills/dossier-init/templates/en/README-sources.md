# Sources

Sources are immutable. Nothing under this folder is ever modified or corrected, even when a
transcript is wrong — corrections go in the living files under `dossier/`, never here.

- `received/` — documents received from the counterpart or the end client: brochures, briefs,
  contracts, anything sent to us.
- `transcripts/` — call recordings and their transcripts; `transcripts/raw/` holds the
  unreviewed, automatic transcript exactly as produced.

Files are named `YYYY-MM-DD_slug` (plus their extension). A text extraction of a PDF sits next
to the PDF, same stem, `.txt` extension.
