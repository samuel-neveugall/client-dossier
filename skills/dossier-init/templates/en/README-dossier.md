# Dossier

This folder is the living memory of the relationship: seven files, each one topic, each line
dated and sourced.

One fact per line. Every line carries a date and a source (a transcript timestamp, a mail, a
file and page). A line without a source is an opinion and says so.

Correct a line rather than add a contradictory one. Each file opens with its own dated header
line, updated whenever the file changes.

- `ACTORS.md` — who is who on every side, grouped by side.
- `HISTORY.md` — chronology, commitments in progress, upcoming.
- `LEARNINGS.md` — how the counterpart speaks and thinks, what the case teaches.
- `TONE.md` — the voice, what is established, the Refused log.
- `CHANNELS.md` — how we communicate and this repository's confidentiality level.
- `OPEN-QUESTIONS.md` — answered, still open, what we would ask the end client.
- `RELATIONSHIP.md` — status, numbers, views, improvements, opportunities.
