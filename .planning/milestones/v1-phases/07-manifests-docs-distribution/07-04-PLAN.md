## Case contract (fixed here)

Format: code.claude.com/docs/en/plugin-evals "Eval suite reference" (read it once before writing).
prompt.md frontmatter keys allowed: schema_version, name, description, tags, plugins, runs,
expected_outcome, model, max_turns, timeout_seconds, allowed_tools, append_system_prompt, env (an
unknown key is a load error). Every case's prompt.md sets `description`, `tags`, `max_turns: 8`,
`timeout_seconds: 240`, `allowed_tools: [Read, Glob, Grep, Skill]`, and nothing else (the CLI sets the
model and the run count). case.yaml, when present, is exactly `schema_version: "1.1"`, `name: <folder>`,
`context:` / `scaffold_script: scaffold.sh`. Grader files: frontmatter only.

Skill grader shape (proven in research, E1/E2): `type: tool_used`, `tool: Skill`,
`input_match: '"skill"\s*:\s*"(?:[\w-]+:)?<skill>"'`, plus `min: 0` and `max: 0` for a "never" grader.
Regex grader shape: `type: regex`, `pattern: '<JavaScript regex>'`, `target: last_message`, optional
`flags: i`.

Seeding scaffold (identical in every case marked "seeded"), executable, `#!/bin/bash`:
`set -eu`; `here="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"`; `root="$(cd "$here/../../.." && pwd)"`;
`git init -q .`; `python3 "$root/skills/dossier-init/scripts/init.py" --target . --language en --counterpart 'Jane Doe|Head of IT|jane@example.com' --confidential-name 'Globex' >/dev/null`;
`git add -A`; `git -c user.name=eval -c user.email=eval@example.invalid commit -qm seed`.

|---|---|---|---|---|

| draft-reply | routing, draft | seeded | `Draft a short reply to Jane confirming Tuesday's meeting.` | draft-fired (dossier-draft, min 1) |

- The case folders (every folder under evals/ holding a prompt.md, `evals/results/` excluded) equal
  EXPECTED_CASES.
- Per case, through one python3 heredoc (argv: the case folder and the repository root), printing
  `label<TAB>expected<TAB>actual` lines: prompt.md frontmatter parses (a `key: value` / flow-list
  subset parser) and its keys are a subset of the allowed set; allowed_tools equals
  `[Read, Glob, Grep, Skill]`; tags include `routing`; the body is non-empty and names no skill
  (no `dossier-` followed by a letter, case-insensitive); at least one `graders/*.md`; each grader's
  type is one of regex, tool_used, tool_order, file_exists, llm, baseline and its keys are the common
  keys (type, weight, arm) plus that type's documented options; each tool_used grader has `tool: Skill`
  and an input_match whose skill name (the longest `dossier(-[a-z]+)?` in it) is a folder under skills/;
  min and max, when present, are integers with min not above max; each regex grader has a non-empty
  pattern and a target among last_message, trace, files (or none); case.yaml, when present, has
  exactly `schema_version: "1.1"`, `name` equal to the folder and a scaffold_script that exists, is
  executable and holds a `set -eu` line.
- write-to-client is pinned: one tool_used grader on dossier-draft with min 1 and one on dossier-ingest
  with min 0 and max 0.
- Each scaffold runs in a fresh `mktemp -d` workspace as `(cd "$ws" && env -i PATH="$PATH" HOME="$h" TMPDIR="${TMPDIR:-/tmp}" TERM=dumb bash "<case>/scaffold.sh")`:

  `dossier.yaml`; ingest-transcript leaves `call-2026-10-10.txt` untracked (`?? call-2026-10-10.txt`
  in `git status --porcelain`). Every workspace and temporary home is removed.
- `assert_grep '^evals/results/$' "$REPO_ROOT/.gitignore"`.
