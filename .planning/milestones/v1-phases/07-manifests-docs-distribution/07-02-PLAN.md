## release.sh contract (fixed here)

- `#!/usr/bin/env bash`, mode 755, header comment: usage `scripts/release.sh <version>`, what it
  changes, that it only creates a LOCAL annotated tag and never contacts a remote (publication needs
  Samuel's explicit approval, D-01), exit codes `0 tagged, 1 refused`. `set -euo pipefail`.
  `die() { echo "release: $1" >&2; exit 1; }`. Bash 3.2: no arrays, no `[[ =~ ]]`; the five paths are
  five plain variables: `CLAUDE_MANIFEST=.claude-plugin/plugin.json`,
  `CODEX_MANIFEST=.codex-plugin/plugin.json`, `CLAUDE_MARKET=.claude-plugin/marketplace.json`,
  `CODEX_MARKET=.agents/plugins/marketplace.json`, `CHANGELOG=CHANGELOG.md`.
- Order: (1) exactly one argument, else die with the usage; (2) semver check: `python3 -I - "$1"`
  with a quoted heredoc running `re.fullmatch` of the semver.org regex (07-RESEARCH Pattern 6) on
  `sys.argv[1]`, exit status only, die `not a semantic version: <value>` (the value printed with
  `printf '%q'`); (3) `cd` to `git rev-parse --show-toplevel` (die outside a repository); (4) the
  five files exist; (5) `git status --porcelain --untracked-files=normal` is empty, else die
  `working tree is not clean; commit first`; (6) `git rev-parse -q --verify "refs/tags/v$version"`
  fails, else die `tag v<version> already exists`; (7) one `python3 -I - "$version" "$CLAUDE_MANIFEST" "$CODEX_MANIFEST" "$CLAUDE_MARKET" "$CODEX_MARKET" "$CHANGELOG"`
  block that loads all five, refuses (exit 1 with the reason on stderr) when the two plugin.json
  versions differ (`the two manifests disagree: A vs B`), when they already equal the new version
  (`already at <version>`), when the changelog does not hold exactly one line matching
  `^## \[Unreleased\][ \t]*$` or already holds a `## [<version>]` heading; computes every new text in
  memory (plugin.json `version` set; in each marketplace, `version` set only on entries that already
  have the key; the Unreleased line replaced by itself, a blank line and `## [<version>] - <today>`
  with today from `date.today().isoformat()`); and only then writes each file (temporary file in the
  same folder, then `os.replace`), JSON as `json.dumps(data, indent=2, ensure_ascii=False) + "\n"`;
  (8) `git add -- <five paths>` and `git commit -q -m "chore(release): v$version" -- <five paths>`;
  (9) `git tag -a "v$version" -m "client-dossier $version"`; (10) print
  `release: tagged v<version> locally. Nothing was pushed.`
- No `eval`, no unquoted expansion, no command that talks to a remote or the network anywhere.
