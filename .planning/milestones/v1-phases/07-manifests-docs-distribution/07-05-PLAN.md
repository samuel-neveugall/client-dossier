## Registry gate (fixed here)

Function `skills_registry_gate` in install-skills.sh: runs
`HOME="$DIST_ROOT/home" npm view skills@1.7.2 --json` (metadata only) from `$DIST_ROOT/cwd`, and the
publish time from `npm view skills time --json`; a python3 -I block prints, one per line,
`checked_at: <UTC ISO time>`, `package: skills@1.7.2`, `version: <v>`, `published: <time>`,
`age_days: <n>`, `repository: <url>`, `deprecated: <no|message>`,
`lifecycle_scripts: <none|names among preinstall install postinstall>`, `publisher: <name part of _npmUser, no e-mail>`,
`provenance: <predicateType|none>`, then `verdict: ok` when version is 1.7.2, lifecycle_scripts is
none, repository contains `github.com/vercel-labs/skills`, deprecated is no, provenance is
`https://slsa.dev/provenance/v1` and publisher is `GitHub Actions`; else
`verdict: refused (<the failed criteria>)`. Returns 0 on ok, 1 on refused; a network or npm failure is
a harness error (scenario_die). The age is informational: provenance from the vercel-labs/skills CI
is the control for the "too new" signal.
