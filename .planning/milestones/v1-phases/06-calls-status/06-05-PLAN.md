## Refinement rule (all three tasks)

A run that fails its gate is read (jsonl, diff, lint, treediff). When the cause is the skill (the
skill not picked, a relative date, an untimed agenda, a deadline field line, a leaked name, a file
written by the status skill, the script not run, the ingest chain skipped, a status changed), refine
`skills/dossier-call/SKILL.md`, `skills/dossier-status/SKILL.md` or the pointer sentences of
`skills/dossier/SKILL.md` to close that specific loophole, naming the observed rationalization in
the Rationalizations table (writing-skills REFACTOR). Keep every pinned phrase; tests/test-skill-call.sh,
test-skill-status.sh, test-skills-task.sh, test-skill-dossier.sh, test-skill-ingest.sh and
test-skill-draft.sh stay green without weakening (a pin may only be replaced deliberately, with the
observed reason in a comment). Never add a fixture token (`Northwind`, `security questionnaire`,
`steering`, `brochure`, `revised-quote`, `pilot-plan`, `signed NDA`, the question tokens or the
prompts) to a skill. Commit the round. A round reruns all three plugin runs of every scenario whose
skill text changed, with fresh OUTDIRs, never a selective rerun; a change to skills/dossier/SKILL.md
reruns both scenarios; a change to dossier-call after task 1's evidence was committed reruns CALL-04
and replaces `evidence/call-green-plugin/`. At most three rounds per skill; then stop and report
with every round's evidence, never relabel. A harness error (exit 2) is a blocker: stop and report
it (the harness cannot change, 03 D-13).
