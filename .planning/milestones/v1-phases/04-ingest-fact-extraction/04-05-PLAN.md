## PDF scenario contract (ROADMAP criterion 1; task 2 writes it, the verify reads it)

- Purpose: one short, paid, agent-run end-to-end run of `dossier-ingest` on a PDF. It is not a
  pressure scenario (INGEST-05's RED and GREEN stay the transcript scenario's): plugin only, no
  baseline variant. Never run by `tests/run.sh` (the file is not named `test-*.sh`).
- Usage: `bash tests/scenarios/ingest-pdf.sh [--runs N] [OUTDIR]`. Defaults: 1 run, OUTDIR
  `mktemp -d`. Each run is capped by lib-scenario.sh's `SCENARIO_BUDGET_USD` (1 USD), with the
  same `SCENARIO_MODEL` as the transcript runs.
- Named constants near the top, one per line as `NAME="value"`:
  `INCOMING_REL="incoming/onboarding-pack.pdf"`, `ISSUE_DATE="2026-10-06"`,
  `CONTACT_NAME="Priya Raman"`, `BACKDATE="2026-09-01"`,
  `PAGE_1="Acme Consulting supplier onboarding pack, issued 2026-10-06."`,
  `PAGE_2="Your procurement contact is Priya Raman, procurement lead at Acme Consulting."`,
  `PAGE_3="Supplier invoices are paid 45 days after receipt."`,
  `PROMPT="Acme Consulting sent us their supplier onboarding pack: incoming/onboarding-pack.pdf. Please ingest it."`.
- Preflight (harness errors, exit 2): `scenario_preflight`; `pdftotext` on PATH (criterion 1
  needs an extraction; the missing-tool path is criterion 5, proven by 04-04 task 3);
  tests/fixtures/make-pdf.py present.
- One run: `build_dossier`; `strip_agents_pointer`; `backdate_last_updated "$dir" "$BACKDATE"`;
  `python3 tests/fixtures/make-pdf.py "$dir/$INCOMING_REL" "$PAGE_1" "$PAGE_2" "$PAGE_3"`; lint.py
  on the prepared dossier must exit 0; `commit_baseline`; the run date (`date +%F`) before and
  after; `run_claude ... yes`; then the harness errors of the transcript harness that apply here:
  missing result event, `is_error` true, `client-dossier:dossier-ingest` absent from the
  system/init skills, `client-dossier:fact-extractor` absent from the system/init agents.
- Output: `OUTDIR/summary.tsv`, `OUTDIR/prompt.txt`, and per run `pdf-<n>.jsonl`, `pdf-<n>.diff`
  (written the way ingest-transcript.sh writes its `.diff`: the diff against the baseline commit
  plus the untracked list) and `pdf-<n>.lint`.
- summary.tsv has exactly these 19 tab-separated columns, in this order: 1 variant (`plugin`),
  2 run, 3 verdict, 4 filed_name, 5 text_extracted, 6 page_lines, 7 right_file, 8 refreshed,
  9 lint_exit, 10 warnings, 11 ingest_skill, 12 extractor_dispatched, 13 filed_date_is_content,
  14 model, 15 claude_code_version, 16 cost_usd, 17 is_error, 18 dossier, 19 jsonl.
  - filed_name: the root-relative path of a regular file directly under `sources/received/`
    whose name matches `^[0-9]{4}-[0-9]{2}-[0-9]{2}_[^/]+\.pdf$` and whose sha256 equals the
    incoming PDF's, else `none`.
  - text_extracted: `yes` when the same stem with `.txt` exists next to filed_name and holds
    `--- page 1 ---`, `--- page 2 ---` and `--- page 3 ---`, else `no`.
  - page_lines: the lines of `added_lines "$dir" "$base" dossier` that start, after optional
    spaces, with `- `, `* ` or `|` and match `p\. [0-9]+`.
  - right_file: `yes` when a line of `added_lines "$dir" "$base" dossier/ACTORS.md` holds
    CONTACT_NAME, else `no`.
  - refreshed, lint_exit, warnings, ingest_skill, extractor_dispatched, model,
    claude_code_version, cost_usd, is_error: computed exactly as ingest-transcript.sh computes
    them. extractor_dispatched never gates (D-12).
  - filed_date_is_content: `yes` when the basename of filed_name starts with `ISSUE_DATE_`
    (D-01); recorded, never gates (D-01 is pinned by 04-04's prose tests).
- Verdict: GREEN when filed_name is not `none`, text_extracted is `yes`, page_lines is at least
  1, right_file is `yes`, refreshed is `yes`, lint_exit is not 1 and ingest_skill is `yes`;
  INCOMPLETE otherwise.
- Exit 0 when every run is GREEN, 1 otherwise, 2 on a harness error (`HARNESS ERROR:` on
  stderr, never a verdict). Last line `SCENARIO ingest-pdf: PASS|FAIL`.
