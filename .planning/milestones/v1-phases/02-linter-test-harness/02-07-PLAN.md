## Decisions taken in this plan (report them in the SUMMARY under "Decisions for Samuel")

- **D-GAP-1 (reversible):** the presence rule applies at every depth. A nested key that is
  `_fold_key`-equal to a gate key stays C1 (a misplaced gate key, as today). A nested key that is
  only a difflib near-miss is C1 only while the gate key it resembles is absent from the top
  level, and ignored otherwise — the same rule as a top-level key, so a counterpart-level
  `confidential_notes` beside a top-level `confidential_names` is silent.
- The cutoff stays at 0.8 and `gate_key_for()` keeps its current contract for `_skipped_key()`,
  which only words the message of a line that is C1 anyway (D-FIX-8).
