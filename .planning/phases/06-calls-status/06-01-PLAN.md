## lib-call.sh contract (fixed here; plans 06-03, 06-05 source it and never edit it)

Header as lib-draft.sh's: sourced after lib-scenario.sh and lib-draft.sh, NOT run by tests/run.sh,
source-safe (functions only), bash 3.2 with no arrays, python3 standard library, every python
snippet run with `python3 -I`, `: "${REPO_ROOT:=...}"`. Every helper prints `no`, `none`, `missing`
or `0` for a missing file, never a traceback.

| Helper | Prints / does |
|---|---|
| `rel_date N [TODAY]` | TODAY (default: python `date.today()`) plus N days, `YYYY-MM-DD` |
| `prep_fixture DIR TODAY` | seeds the CALL-04 fixture (below) into a dossier built by `build_dossier`, backdates every living file's `Last updated:` to D(-10) with `backdate_last_updated`; commits nothing |
| `check_prep_fixture DIR TODAY` | `scenario_die` naming the missing seed, else nothing |
| `status_fixture DIR TODAY` | writes the CALL-05 fixture (below) AND commits it in dated stages with `set_mtime` and `commit_at`; echoes the final HEAD |
| `check_status_fixture DIR TODAY` | `scenario_die` naming the broken seed, trap, count, date or token uniqueness, else nothing |
| `call_question_order FILE TOK1 TOK2 TOK3` | `yes` when each token occurs (case-insensitively) on a line of FILE that also holds a `?` and the first such line numbers strictly ascend in argument order; `no` when all occur but not in that order; `missing` when one does not occur or FILE is missing |
| `call_heading_present FILE ERE` | `yes` when a heading line of FILE (one matching `^#{1,6} `) matches ERE case-insensitively, the ERE applied to the whole line, else `no` |
| `call_minutes_empty FILE ERE` | for the last heading line matching ERE (case-insensitive, applied to the whole line): `yes` when every line after it, up to the next heading or the end, is blank or inside an HTML comment, `no` when one is not; `none` when no heading matches or FILE is missing (an anchored ERE keeps `## Agenda (30 minutes)` out) |
| `call_timed_lines FILE` | the number of timed lines (rule below the table) |
| `call_line_present FILE ERE` | `yes` when any line matches ERE, `no` otherwise, `none` without FILE |
| `text_has_ci JSONL NEEDLE` | `yes` when the LAST result event's `result` text contains NEEDLE case-insensitively, after folding `-` and `_` to a space in both, else `no` |
| `call_reads JSONL` | the number of assistant `Read` tool_uses plus `Bash` tool_uses whose command contains `cat `, `head ` or `sed -n` |
| `stop_blocked JSONL` | `yes` when the stream holds the Stop hook's text `but nothing under dossier/ did`, else `no` |
| `porcelain_empty DIR` | `yes` when `git --no-optional-locks -C DIR status --porcelain` prints nothing, else `no` |
| `tree_manifest DIR` | one line `<sha256>  <relative path>` per regular file under DIR, `.git` included, sorted |

Timed-line rule of `call_timed_lines`: a line counts when it holds no `@` and matches, as a
Python regular expression with `re.I`, either `(?:^|[^0-9:@])[0-9]{1,2}:[0-9]{2}(?![0-9])` or
`[0-9]+ ?min`. The `@` exclusion keeps transcript locators such as `(call 2026-10-01 @12:34)` out.

`draft_new_files`, `draft_name_ok`, `draft_header_field`, `draft_reldate_count`, `draft_leak`,
