## status.py contract (fixed here; plans 06-03, 06-04 and 06-05 rely on it)

**Header.** Shebang `#!/usr/bin/env python3`; module docstring in file_source.py's style ("Mechanics
tier only ... Judgement lives in skills/dossier-status/SKILL.md"), stating read-only, the CLI and the
exit codes, and why lint is found from `__file__` (06-RESEARCH P1: the plugin-root variable is
substituted in skill text but empty in the Bash tool) and run as a subprocess (an import would write
bytecode next to the plugin's `scripts/`).

**CLI.** `status.py [--json] [--today YYYY-MM-DD] [--lint PATH] [PATH]`; PATH defaults to `.`.
`--today` must fullmatch `[0-9]{4}-[0-9]{2}-[0-9]{2}` and be a real calendar date, else argparse
reports the usage error (exit 2). Default today: `datetime.date.today()`.

**Exit codes.** 0 report printed, whatever it holds (status is informational, not a gate). 2 the
path does not exist, no `dossier.yaml` upward (`error: no dossier.yaml found from <path> upward` on
stderr), `dossier.yaml` unreadable, or a usage error. 3 internal error: `main` wraps `_run` like
lint.py's `main` and prints `error: internal status failure: <Type>: <message>` on stderr.

**Ported pieces.** Copied from scripts/lint.py and pinned by tests: `find_root` byte-identical
(`sed -n '/^def find_root/,/^    return None$/p'`); these top-level assignments with an identical
`ast.dump` of their value: `CONFIG_NAME`, `LIVING_DIR`, `LIVING_FILES`, `OUTBOUND_DIR`,
`EXEMPT_PATHS`, `OS_METADATA_NAMES`, `GITKEEP`, `BINARY_EXTS`, `PROTOCOL_FIELDS`,
`STATUS_HEADER_WINDOW`, `DEFAULT_STALENESS_DAYS`, `_LAST_UPDATED_RE`, `_DATE_PREFIX_RE`, `_FIELD_RE`;
behavioural ports of `visible_lines` (plus fenced-code skipping), `read_text_safe` (no symlink
follow, 5 MB cap, `utf-8-sig`, None on error), `sanitise_path`, `is_absolute_date`,
`read_status_header` (first `STATUS_HEADER_WINDOW` lines, `_FIELD_RE.fullmatch`, first wins),
`_tolerant_streams`. Its own trailing-source regex captures the parenthesis content:
`\(([^()]+)\)\.?\s*$`. Dates are found with `(?<![0-9])([0-9]{4})-([0-9]{2})-([0-9]{2})(?![0-9])`
and kept only when `datetime.date` accepts them.

**JSON (`--json`), one object, `ensure_ascii=True`:**
`root` (absolute), `today`, `status_line` (string or null),
`commitments` (list of `{file, line, side, heading, date, state, text}`, state `overdue` or
`due_soon`, side `ours` or `theirs`), `upcoming` (list of `{file, line, date, text}`),
`last_reflected` (date or null), `unreflected_sources` (list of `{path, filed, how}`, how `git`,
`untracked` or `mtime`), `overdue_drafts` (list of `{path, status, deadline}`), `stale_files` (list
of `{path, last_updated, days}`), `staleness_days` (int), `lint` (`{available, exit, errors,
warnings, findings: [{path, line, severity, id, message}], info: [...]}`; `exit`, `errors` and
`warnings` null when lint is unavailable or did not run), `notes` (list of strings). Lists are sorted
by date then path.

**Text (default)**, every path and text through the escaper, every empty list printed as `- none`:
`Dossier: <root>`, `Today: <date>`, `One-line status: <line>` (or `none recorded`),
`Commitments overdue:`, `Commitments due within 7 days:`, `Upcoming within 7 days:`,
`Overdue drafts:`, `Sources not yet reflected (newest Last updated: <date or none>):`,
`Stale living files (staleness_days <n>):`,
`Lint: <n> error(s), <m> warning(s)` or `Lint: unavailable` or `Lint: did not run (<reason>)`, then
its findings, and `Notes:`. Items are `- ` lines carrying the date, the side and owner text or the
path, and the source location `[<file>:<line>]` where there is one.

**git.** One `git log` for filing dates:
`git --no-optional-locks -c core.fsmonitor=false -C <root> log --no-renames --relative --diff-filter=A --name-only -z --format=@%at -- sources`
(newest first: the first date seen per path is its latest add); untracked:
`git ... ls-files --others --exclude-standard -z -- sources`; staged but never committed:
`git ... diff --cached --name-only --diff-filter=A -z -- sources`; repository check:
`git ... rev-parse --is-inside-work-tree`. Every git call has a 10 s timeout and the prefix
`git --no-optional-locks -c core.fsmonitor=false -C <root>`; a missing git or a failure means "not
a repository": mtime dates for every source and a note. Dates from `%at` and from mtimes are local
dates (`datetime.date.fromtimestamp`).

**Cited outbound path.** The source's first token starting with `outbound/` (trailing `.,;` stripped)
is resolved under the root; it is used only when its real path stays inside `<root>/outbound/` and it
is a regular file that is not a symlink; otherwise the line falls back to its last date and a note
names the citation.
