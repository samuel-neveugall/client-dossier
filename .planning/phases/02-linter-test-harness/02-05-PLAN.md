## Why this is the one committed fixture, and what it is allowed to lose

> **Read `02-01-PLAN.md` § "Deviation from locked decision D-28" first.** D-28 names **two**
> committed trees — `tests/fixtures/lint/clean/` as well as this French one — and this plan set
> commits only this one. That divergence is a surfaced deviation from a locked decision,
> **pending Samuel's arbitration**, not a settled choice. If it is rejected, the committed clean
> tree and its drift assertion are added here, in the shape that section spells out.

D-28 keeps the French fixture committed because it must carry content the producer will never
generate — deliberate relative-date words, deliberately unsourced bullets, a deliberately
multi-line HTML comment — so generating it is not an option. The clean fixture stays generated
(Q-7): a committed scaffold silently loses `sources/transcripts/`, because the producer writes
no `.gitkeep` there and git tracks no empty directory. The committed French tree may lose that
directory too and it is harmless — no check in this phase reads it — but record the fact in the
fixture's own README so nobody later mistakes this tree for a faithful copy of the producer's
output. The sync guarantee belongs to the generated clean fixture, not to this one.
