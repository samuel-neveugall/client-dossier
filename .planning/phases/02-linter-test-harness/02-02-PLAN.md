<objective>
Expand the proven tracer with the five outbound error classes — the status block (E1, E2, E3),
the filename convention (E4) and the confidential-name leak check (E5) — plus the consent gate
that can switch E5 off and the README exemption boundary that keeps a freshly scaffolded
dossier clean.

Purpose: these are the checks that make `outbound/` safe to hand to a human, and E5 is the one
whose two halves (text and filename) exercise two different code paths — the research measured
that the obvious word-boundary construct silently misses every name embedded in a
`YYYY-MM-DD_slug` filename, which is every outbound filename there is.
Output: five more error classes firing in isolation, with the fail-closed consent gate pinned
by a fixture rather than by prose.
