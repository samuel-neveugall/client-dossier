## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `--language` / `--status-header` CLI values → `dossier.yaml` bytes | Free text supplied on the command line by a human or by a skill turns into structure in a configuration file. This is the boundary Phase 1's threat T-01-01 already hardened; this plan narrows the remaining gap. |
| `dossier.yaml` bytes → the linter's parser | The producer's output is the consumer's input. A spelling the producer emits bare and the consumer must not coerce is where the two halves meet. |
