## lib-dist.sh contract (fixed here; plans 07-05, 07-07 and 07-09 source it and never edit it)

Header: the free, isolated install checks of Phase 7 (D-04, D-17), NOT run by tests/run.sh (the
folder `tests/dist/` is never globbed); source-safe (functions and variable definitions only, the
EXIT trap is set by `dist_init`, never at source time); bash 3.2, no arrays; python3 standard library
through `python3 -I`. It sources `tests/scenarios/lib-scenario.sh` for `REPO_ROOT`, `scenario_die`
(exit 2, `HARNESS ERROR:`) and `scrub_check`, and copies neither.

| Helper | Does |
|---|---|
| `dist_init NAME` | records NAME, `DIST_FAILED=0`; captures the real locations once: `DIST_REAL_HOME="$HOME"`, `DIST_REAL_CLAUDE="${CLAUDE_CONFIG_DIR:-$HOME/.claude}"`, `DIST_REAL_CODEX="${CODEX_HOME:-$HOME/.codex}"`; creates `DIST_ROOT=$(mktemp -d)` and the subfolders `cwd`, `home`, `cfg`, `src`; sets `trap 'rm -rf "$DIST_ROOT"' EXIT` |
| `dist_help_has BIN SUBWORDS NEEDLE` | runs `BIN SUBWORDS --help` (SUBWORDS split on spaces on purpose) and calls `scenario_die` when NEEDLE is absent from the output or BIN is not on PATH |
| `dist_clone_head DEST` | `sha=$(git -C "$REPO_ROOT" rev-parse HEAD)`; `git clone -q --no-checkout "$REPO_ROOT" DEST`; `git -C DEST checkout -q --detach "$sha"`; `scenario_die` when the clone's HEAD is not that sha; prints `source: HEAD <12-char sha>` and, when `git -C "$REPO_ROOT" status --porcelain` is not empty, `note: uncommitted changes are not installed; this check installs HEAD only` |
| `dist_real_snapshot` | prints one line `<sha256 or absent>  <label>` for each of `$DIST_REAL_CLAUDE/settings.json`, `$DIST_REAL_CLAUDE/plugins/known_marketplaces.json`, `$DIST_REAL_CLAUDE/plugins/installed_plugins.json`, `$DIST_REAL_CODEX/config.toml`, `$DIST_REAL_HOME/.agents/plugins/marketplace.json`, plus one line listing the sorted entry names of `$DIST_REAL_CLAUDE/skills` and of `$DIST_REAL_HOME/.agents/skills` (labels use `~` and never print the home path) |
| `dist_real_unchanged BEFORE` | recomputes the snapshot; prints `OK real configuration unchanged` and returns 0 when equal, else prints the differing labels and returns 1 |
| `dist_redact` | filter, stdin to stdout: `$REPO_ROOT` becomes `<repo>`, `$DIST_ROOT` becomes `<tmp>`, `$DIST_REAL_HOME` becomes `~` (python3 -I, values through argv) |
| `dist_ok LABEL` / `dist_bad LABEL` | print `ok: LABEL` / `FAIL: LABEL` (the latter also on stderr) and count failures in DIST_FAILED |
| `dist_finish` | prints `DIST <NAME>: PASS` and exits 0 when DIST_FAILED is 0, else `DIST <NAME>: FAIL` and exits 1 |

Every CLI call of a dist script runs as `(cd "$DIST_ROOT/cwd" && CLAUDE_CONFIG_DIR=... HOME=... <cmd>)`
(Codex: `CODEX_HOME=... HOME=...`) with its output piped through `dist_redact` into the script's
stdout, so a logged run never carries the real home path.
