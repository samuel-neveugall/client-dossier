**Sections, in this order, each a whole line:** `# dossier-draft`, `## Find the dossier`,
`## What to write`, `## Read before writing`, `## Write the draft`, `## Review`,
`## Apply the findings`, `## Check with the linter`, `## Record in history`, `## Report`,
`## Without the linter`, `## Rationalizations`.

**Command lines.** The non-blank, non-`#` lines of all ```bash blocks of SKILL.md are exactly
these six, each alone on its line, no continuation:
1. `date +%F`
2. `ls -1t '<root>/outbound/<folder>'`
3. `test -e '<root>/outbound/<folder>/<YYYY-MM-DD>_<slug>.<ext>'`
4. `git -C '<root>' config user.name`
5. `test -f ${CLAUDE_PLUGIN_ROOT}/scripts/lint.py`
6. `python3 ${CLAUDE_PLUGIN_ROOT}/scripts/lint.py '<root>'`

Their placeholder set is exactly `<root>`, `<folder>`, `<YYYY-MM-DD>`, `<slug>`, `<ext>`. Line 3
sits under `## Write the draft`; line 5 comes before line 6, both under `## Check with the linter`;
line 4 sits under `## Record in history`.

**Kind table** (D-01), rows starting exactly:
`| `mail` | `outbound/mails/` |`, `| `message` | `outbound/mails/` |`,
`| `deliverable` | `outbound/deliverables/` |`, `| `note` | `outbound/deliverables/` |`, with a
`Subject:` column (required for both mails/ kinds, optional otherwise) and a structure column
(fifth `## ` heading of TONE for mail and message, fourth for deliverable and note, research A1).

**Status block** (D-02, spec §3.3): exactly one ```markdown fenced block of SKILL.md starts with
the line `<!--`; its lines are, in order: `<!--`, `Status: draft`, `To: <recipient>`,

`Rules: no confidential names; see knowledge/DOCTRINE.md`, `-->`, a blank line, `<body>`. Its
placeholder set is exactly `<recipient>`, `<subject>`, `<YYYY-MM-DD>`, `<body>`.

**History lines** (D-04): one ```text fenced block holds exactly these three lines:
- `- <YYYY-MM-DD>: draft <kind> '<slug>' written, to be sent by <sender>, deadline <YYYY-MM-DD> (outbound/<folder>/<file>).`
