## Deviations from the spec

**The deviation, restated in full because this plan is where it is discharged.**
`skills/dossier-init/scripts/init.py` and `skills/dossier-init/templates/{en,fr}/` live inside
the skill folder rather than at the repository-root `templates/` that spec §4's architecture tree
shows. `scripts/lint.py` (Phase 2, shared by several skills) is unaffected and still lands at the
repository-root `scripts/`.

**Authority:** locked decisions **D-05** and **D-06** in
`.planning/phases/01-scaffold-templates/01-CONTEXT.md`, validated by Samuel during discuss-phase
(`Status: Ready for planning`). D-06 says in its own words that "the spec's architecture tree (§4,
`templates/` at the root) is to be amended accordingly during this phase". `01-RESEARCH.md`
confirms the layout with two official sources — the Agent Skills open standard's optional
`scripts/`/`assets/` subfolders "plus additional files/directories", and the Claude Code plugin
reference's plugin-skill directory with `scripts/`, addressed through `${CLAUDE_SKILL_DIR}`.

**Reversibility: costly** (as rated in D-05/D-06). Undoing it means rewriting the skill prose, the
Phase 2 bash tests and the inline fallback in lockstep. Not one-way: no migration, no published
contract, nothing recorded in a user's dossier.

**No `checkpoint:decision` gates it** — `costly`, not `one-way`, and already put to Samuel and
answered in discuss-phase. Its weight is discharged instead by Task 2 and Task 3 below, which make
the spec and `CLAUDE.md` state the real layout, so the next reader meets the decision in the
documents rather than in a surprise.
