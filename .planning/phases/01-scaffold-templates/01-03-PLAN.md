## Deviations from the spec

None introduced by this plan. It inherits the D-05/D-06 deviation documented in
`.planning/phases/01-scaffold-templates/01-01-PLAN.md` → "Deviations from the spec".

One decision this plan makes explicit, above spec §4.5: spec §4.5 describes a single English
template set translated by the skill at scaffold time. **D-09 ships two hand-maintained
variants**, `en/` and `fr/`, so that French output is deterministic and testable rather than
model-dependent, and keeps §4.5's translate-from-English behaviour for every other language.
That is a superset of §4.5, not a contradiction: the spec's described behaviour still runs for
any language without a variant, which plan 01-02's `resolve_template_dir` already implements.
